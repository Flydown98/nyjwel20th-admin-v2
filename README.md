# NYJWEL 20th Admin v2 — v0.3.1 Full Field

## 포함 기능
- 기존 v0.2 데이터 유지 호환
- 현황 자동 갱신
- QR 카메라 스캔 / 수동 코드 접수
- 모든 QR 스캔 시 팝업
  - 개인: 팝업 표시 후 1.4초 뒤 자동 접수, 즉시접수 버튼 제공
  - 단체: +/- 인원 스텝퍼 후 확인 버튼을 눌러야 접수
- 개인 체크인: 도착 + 기념품 + 좌석 자동배정 + 문자큐
- 단체 체크인:
  - 사전등록 인원 범위까지만 좌석
  - 사전등록보다 적게 오면 실제 인원만 좌석
  - 사전등록보다 많이 오면 초과 인원은 스탠딩
- QR 없이 온 현장 신규 참가자 등록: 좌석 미배정/스탠딩
- 단체 관리: 같은 기관 후보를 보고 직접 단체 지정/해제
- 좌석 현황 + 미도착 좌석 전체 해제
- 행운권 추첨: 도착자 중 중복 당첨 제외
- 당첨 상품 수령 처리
- 문자 대기열 / 행사 전날 안내문자
- Python 문자나라 relay용 `/relay/pending`, `/relay/result`
- 1분 자동백업 + JSON 다운로드 + 참가자 CSV

## 재배포 전 중요
현재 v0.2에서 참가자 데이터를 이미 반영했다면 먼저 `백업 → JSON 다운로드`를 눌러 PC에 저장하세요.
재배포 후 참가자 수가 0으로 보이면 `백업 → JSON 백업 복원`으로 그 파일을 올리면 됩니다.
