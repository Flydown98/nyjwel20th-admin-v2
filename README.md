# NYJWEL 20th Admin v2 — v0.8.0.0

이번 버전 핵심
- 개인 QR 접수 성공 후 팝업 자동 닫힘
- 중복 QR: 신규 처리/문자 재발송 없이 '이미 접수됨' 표시
- 내부 복지관/사회서비스/활동지원/이용인/팀 계열은 자동 기관 단체 후보에서 제외
- Cloudtype 서버에서 문자나라 API 직접발송
- EUC-KR 인코딩 적용
- 문자나라 테스트 발송 버튼
- 개별 수동 문자 발송
- 개인 QR 접수 완료 시 좌석 안내 문자 자동발송
- 단체 QR 접수 완료 시 대표자에게 이번 배정 좌석 목록 문자 자동발송
- 모바일 반응형 강화
- PWA(홈 화면 설치형) 기본 지원
- 기존 JSON 백업 복원 유지

Cloudtype 환경변수
- ADMIN_PASSWORD
- MUNJANARA_ID
- MUNJANARA_PW
- MUNJANARA_SENDER
- MUNJANARA_TEST_RECEIVER
- SMS_RELAY_TOKEN (이제 직접발송에는 필요 없지만 예전 relay 호환용으로 남겨도 됨)

적용 전
1. 현재 서버에서 JSON 백업 다운로드
2. ZIP 파일을 GitHub 저장소에 덮어쓰기
3. Cloudtype 재배포
4. 데이터가 비었으면 백업 메뉴에서 JSON 복원
5. 문자 메뉴에서 '테스트 문자 발송' 먼저 확인
6. 개인 QR 1명 테스트
7. 단체 QR 1팀 테스트

주의
- Cloudtype 직접발송이 성공하면 집 PC relay는 더 이상 필요하지 않습니다.
- 전날 안내문자는 자동 일괄발송 UI를 제거하고 개별 발송 중심으로 변경했습니다.

# v0.9.0 · 행사 운영 안정화판

이번 버전은 기능 추가보다 **행사 당일 사고 방지와 운영 가시성**을 우선합니다.

## 적용된 주요 개선
1. 단체 일부 도착 시 미도착자의 기존 예약좌석을 자동 해제하지 않음.
2. 행사 시작 후 필요할 때만 `미도착 예약좌석 해제` 버튼으로 일괄 해제.
3. 대시보드에 실제 입장(등록 도착 + 단체 초과), 최근 10분 입장, 미도착, VIP/내빈 미도착, 이동지원 미도착, 좌석 미배정, 문자 실패, 남은 좌석 표시.
4. html5-qrcode를 npm 의존성으로 포함하고 `/vendor/html5-qrcode.min.js`에서 자체 서비스하여 외부 CDN 의존 제거.
5. 서버/화면 버전이 다르면 상단에서 즉시 경고.
6. 공개 좌석배치도는 하드코딩 10×2가 아니라 실제 `state.seats`의 활성 좌석 구조를 읽어 그림. 본인 좌석만 빨간색 강조.
7. 휠체어 포함 그룹은 휠체어 이용인만 휠체어 가능 좌석을 먼저 사용하고 나머지 동반자는 일반 연속석을 우선 배정.
8. 참가자별 문자 발송 이력과 실패 문자 재발송 기능.
9. 좌석 안내 URL을 `/s/<서명키>` 형태로 단축.
10. `ADMIN_PASSWORD`가 없으면 운영판 서버가 시작되지 않도록 fail-closed.
11. `행사 운영 잠금` 모드 추가. 현장 접수/문자/추첨/수동 좌석은 유지하고 XLSX·복원·대규모 재배치 등 위험 작업은 잠금.
12. 기기별 `접수대 이름` 저장. 접수대1 / 배리어프리 / VIP 데스크 등으로 로그 구분 가능.
13. VIP/내빈·휠체어/이동지원 대상 도착 시 SSE로 모든 관리자 화면에 우선도착 알림.
14. 인터넷/서버/문자/백업 상태를 대시보드 상단에서 상시 확인.
15. 행운권 `진행자 화면`과 `무대 전체화면` 분리. 무대 화면은 별도 서명 링크로 열리고 추첨 시작/당첨 결과를 SSE로 동기화.
16. 별도 `SYSTEM_DEMO_MODE` 지원. 실제 SMS와 Drive 저장을 발생시키지 않고 전체 기능을 시연 가능.
