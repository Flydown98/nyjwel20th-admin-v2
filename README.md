# NYJWEL 20th Admin v2 — v0.7.1.0

이번 버전 핵심
- 개인 QR 접수 성공 후 팝업 자동 닫힘
- 중복 QR: 신규 처리/문자 재발송 없이 '이미 접수됨' 표시
- 내부 복지관/사회서비스/활동지원/이용인/팀 계열은 자동 기관 단체 후보에서 제외
- Cloudtype 서버에서 문자나라 API 직접발송
- EUC-KR 인코딩 적용
- 문자나라 테스트 발송 버튼
- 개별 수동 문자 발송
- 개인 QR 접수 완료 시 좌석 안내 문자 자동발송
- 단체 QR 접수 완료 시 대표자에게 이번 배정 좌석 목록 문자 자동발송
- 모바일 반응형 강화
- PWA(홈 화면 설치형) 기본 지원
- 기존 JSON 백업 복원 유지

Cloudtype 환경변수
- ADMIN_PASSWORD
- MUNJANARA_ID
- MUNJANARA_PW
- MUNJANARA_SENDER
- MUNJANARA_TEST_RECEIVER
- SMS_RELAY_TOKEN (이제 직접발송에는 필요 없지만 예전 relay 호환용으로 남겨도 됨)

적용 전
1. 현재 서버에서 JSON 백업 다운로드
2. ZIP 파일을 GitHub 저장소에 덮어쓰기
3. Cloudtype 재배포
4. 데이터가 비었으면 백업 메뉴에서 JSON 복원
5. 문자 메뉴에서 '테스트 문자 발송' 먼저 확인
6. 개인 QR 1명 테스트
7. 단체 QR 1팀 테스트

주의
- Cloudtype 직접발송이 성공하면 집 PC relay는 더 이상 필요하지 않습니다.
- 전날 안내문자는 자동 일괄발송 UI를 제거하고 개별 발송 중심으로 변경했습니다.

## v0.7.1 그룹 운영 규칙 수정
- 동반그룹은 대표자 개념 없이 어느 구성원의 QR을 찍어도 전체 그룹 접수창이 열림
- QR을 찍은 참가자를 이번 접수 대상에서 우선 처리
- 그룹 안내문자는 QR을 제시한 참가자의 연락처로 우선 발송
- 같은 외부기관 참가자가 2명 이상이면 자동으로 하나의 기관그룹으로 묶음
- 동반신청자도 같은 외부기관이면 별도 '동반코드' 이름 대신 기관명으로 운영
- 기관으로 묶이지 않는 동반신청 그룹 이름은 단순히 `동반`
- 기본 자동그룹 제외어에 `남양주시`, `남양주시장애인복지관`, 내부 팀/사회서비스/활동지원 관련 키워드 포함
- 그룹관리 화면에서 자동기관묶음 제외어를 직접 추가/삭제 가능
- 제외어 저장 후 자동그룹을 즉시 재구성 가능
