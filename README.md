# NYJWEL 20th Admin v2 — v0.5.0

이번 버전 핵심
- 개인 QR 접수 성공 후 팝업 자동 닫힘
- 중복 QR: 신규 처리/문자 재발송 없이 '이미 접수됨' 표시
- 내부 복지관/사회서비스/활동지원/이용인/팀 계열은 자동 기관 단체 후보에서 제외
- Cloudtype 서버에서 문자나라 API 직접발송
- EUC-KR 인코딩 적용
- 문자나라 테스트 발송 버튼
- 개별 수동 문자 발송
- 개인 QR 접수 완료 시 좌석 안내 문자 자동발송
- 단체 QR 접수 완료 시 대표자에게 이번 배정 좌석 목록 문자 자동발송
- 모바일 반응형 강화
- PWA(홈 화면 설치형) 기본 지원
- 기존 JSON 백업 복원 유지

Cloudtype 환경변수
- ADMIN_PASSWORD
- MUNJANARA_ID
- MUNJANARA_PW
- MUNJANARA_SENDER
- MUNJANARA_TEST_RECEIVER
- SMS_RELAY_TOKEN (이제 직접발송에는 필요 없지만 예전 relay 호환용으로 남겨도 됨)

적용 전
1. 현재 서버에서 JSON 백업 다운로드
2. ZIP 파일을 GitHub 저장소에 덮어쓰기
3. Cloudtype 재배포
4. 데이터가 비었으면 백업 메뉴에서 JSON 복원
5. 문자 메뉴에서 '테스트 문자 발송' 먼저 확인
6. 개인 QR 1명 테스트
7. 단체 QR 1팀 테스트

주의
- Cloudtype 직접발송이 성공하면 집 PC relay는 더 이상 필요하지 않습니다.
- 전날 안내문자는 자동 일괄발송 UI를 제거하고 개별 발송 중심으로 변경했습니다.


## v0.4.1 수정
- 문자 화면의 오래된 이벤트 핸들러 때문에 이후 JS가 중단되던 문제 수정
- JSON 백업 복원 버튼 정상 작동
- 문자 상태 확인/테스트 버튼 정상 작동
- 캐시 버전 분리로 구버전 app.js 혼합 방지


## v0.4.2 좌석맵 수정
- A~Y 25개 행
- 각 행 좌측 10석 + 중앙 런웨이 + 우측 10석
- 배정·미도착: 흰색 + 이름
- 도착완료: 초록색
- A~C 런웨이 안쪽 5석: 주요 귀빈(금색 테두리)
- A~C 바깥쪽 5석: 장애인·휠체어(파란 테두리)
- D~F: 내빈 관련 좌석(금색 계열 테두리)
- G~Y: 일반석


## v0.5 참가자 · 그룹 · 좌석관리
### 참가자
- 이름/연락처/기관/상태/도착/휠체어/장애인당사자/복지관이용/활성/메모 수정
- 참여/미참여/취소/비활성 상태 관리
- 접수/접수취소
- 관리자 수정 로그 기록

### 그룹
- 외부기관 자동 후보(내부 복지관/사회서비스 계열 제외)
- 기관 그룹 활성화
- 대표자 그룹 직접 생성
- 대표자 변경/구성원 수정
- 동반신청 companionGroup 자동 표시 및 관리
- 그룹 해제는 참가자 삭제가 아니라 연결만 해제

### 좌석
- 좌석 클릭 → 참가자 직접 지정
- 기존 좌석 참가자와 교환 또는 기존 참가자를 미배정 처리
- 좌석 해제
- 미배정 참가자 보기
- 미배정자 일괄배치
- 대표자/동반 그룹 연속좌석 우선
- 미도착 좌석 일괄 해제
