# 남양주시장애인복지관 20주년 현장 관리자 V2

이 프로젝트는 행사 당일 Google Sheet/Apps Script를 운영 DB로 사용하지 않고, **Cloudtype 서버 내부 SQLite DB**를 사용해 QR 접수 속도를 높이는 현장용 관리자입니다.

## 구조

- 행사 전 신청: 기존 V1 그대로 유지
- 행사 직전: Google Sheet를 `20주년 행사 QR 접수 명단.xlsx`로 다운로드
- V2 관리자에서 Excel 업로드
- 행사 당일: SQLite `data/event.db`만 사용
- 문자: SOLAPI
- 백업: V2 관리자에서 Excel로 다운로드
- 비상시: 기존 V1 관리자 사용

## 포함 기능

- Excel 참가자/좌석/기존 로그 가져오기
- QR 체크인
- QR 리더기 입력 및 브라우저 카메라 QR 스캔
- 미배정 참가자 현장 자동 좌석배정
- 휠체어 이용인 우선 좌석배정
- 참가자 검색
- 좌석 변경 / 자동배정
- 도착 취소
- 현장 신규등록 + 즉시 입장처리
- 좌석 현황판
- 접수로그
- SOLAPI 체크인/좌석변경 자동문자
- SOLAPI 테스트 발송
- 전체 Excel 백업
- 행사 전 테스트 도착상태 초기화

# 2. Cloudtype 설정

현재 만들어 둔 Cloudtype 서비스에서 아래처럼 설정합니다.

- Runtime: Node.js
- Node.js: 24
- Region: Seoul - Korea
- Port: `3000`
- Install command: `npm install`
- Build command: 비워두기
- Start command: `npm start`

## 환경변수

필수:

- `ADMIN_TOKEN` = 관리자 로그인용 긴 비밀번호

SOLAPI 사용 시 추가:

- `SOLAPI_API_KEY` = SOLAPI API Key
- `SOLAPI_API_SECRET` = SOLAPI API Secret
- `SOLAPI_SENDER` = SOLAPI에 등록된 발신번호 (하이픈 없이 권장)

중요: 실제 Key/Secret은 GitHub에 입력하지 말고 Cloudtype 환경변수에만 넣습니다.

# 3. 배포

배포 후 `접속하기`를 눌러 관리자 페이지를 엽니다.

관리 토큰에 `ADMIN_TOKEN` 값을 입력해 로그인합니다.

# 4. 처음 1회 Excel 가져오기

관리자 → `설정·백업` → `엑셀 명단 가져오기`

현재 사용 중인:

`20주년 행사 QR 접수 명단.xlsx`

파일을 선택하고 **초기화 후 전체 가져오기**를 누릅니다.

현재 파일 형식에서 다음 시트를 읽습니다.

- `참가자`
- `좌석설정`
- `설정`
- `접수로그`

기존 파일의 열 이름을 기준으로 자동 변환합니다.

# 5. 행사 전까지 신규 신청이 계속 들어오는 경우

기존 V1 신청 페이지는 그대로 운영합니다.

행사 전날 또는 행사 당일 아침:

1. 최신 Google Sheet를 Excel로 다운로드
2. V2 관리자 → `설정·백업`
3. 최신 Excel 선택
4. **신규/변경만 합치기** 클릭

이미 V2에서 도착 처리된 참가자는 합치기 과정에서 현장 도착/좌석 상태를 보존합니다.

# 6. QR 체크인

관리자 첫 화면 `QR 접수` 사용.

접수대별로 `접수대 1`, `접수대 2`처럼 이름을 설정합니다.

방법 A: USB/블루투스 QR 리더기
- QR 입력칸 클릭
- 스캔
- 리더기가 Enter를 보내면 자동 접수

방법 B: 휴대폰 Chrome
- `카메라로 QR 스캔`
- 카메라 권한 허용
- QR 인식

체크인 시:

1. 참가자 찾기
2. 이미 접수됐는지 확인
3. 좌석이 없으면 SQLite에서 즉시 자동배정
4. 도착 처리 저장
5. 화면에 이름/좌석 즉시 표시
6. SOLAPI가 설정되어 있으면 체크인 문자는 뒤에서 발송

따라서 문자 발송을 기다리느라 QR 화면이 멈추지 않습니다.

---

# 7. 좌석 배정 기준

기존 Excel `좌석설정`의 값을 사용합니다.

일반 참가자:
- `사용여부 = TRUE`
- `일반자동배정 = TRUE`
- `정렬순서`가 빠른 좌석부터 배정

휠체어 이용인:
- 우선 `휠체어자동배정 = TRUE` 좌석 사용
- 해당 좌석이 모두 찼으면 일반 자동배정 가능 좌석으로 넘어감

이미 다른 참가자에게 배정된 좌석은 자동 제외합니다.

---

# 8. SOLAPI

SOLAPI 콘솔에서 다음이 준비돼야 합니다.

1. 계정 가입/충전
2. 발신번호 등록
3. API Key / API Secret 발급
4. Cloudtype 환경변수 입력

환경변수 설정 후 Cloudtype 재배포.

V2 관리자 → `설정·백업` → `SOLAPI 테스트`에서 본인 휴대폰으로 1통 발송해 확인합니다.

자동 발송 문구:

체크인:

```
[남양주시장애인복지관]
개관 20주년 기념행사 현장접수가 완료되었습니다.
좌석: D-00
감사합니다.
```

좌석 변경:

```
[남양주시장애인복지관]
20주년 기념행사 좌석이 변경되었습니다.
변경 좌석: D-00
안내데스크 안내를 따라주세요.
```

---

# 9. 백업

무료 Cloudtype 디스크는 영구 저장을 보장하는 저장소가 아니므로 V2 관리자에서 수시로 Excel 백업을 다운로드합니다.

`설정·백업` → `현재 전체 데이터 Excel 백업`

백업 파일에는:

- 참가자
- 좌석설정
- 접수로그
- 문자로그
- 설정

이 들어갑니다.

권장 시점:

- 행사 시작 전
- 접수 시작 30분 후
- 주요 접수 마감 후
- 행사 종료 직후

행사 당일에는 **Cloudtype 재배포/서비스 재생성 금지**를 권장합니다.
