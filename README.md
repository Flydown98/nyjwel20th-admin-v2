# NYJWEL 20th Admin v2 — v0.8.0.0

이번 버전 핵심
- 개인 QR 접수 성공 후 팝업 자동 닫힘
- 중복 QR: 신규 처리/문자 재발송 없이 '이미 접수됨' 표시
- 내부 복지관/사회서비스/활동지원/이용인/팀 계열은 자동 기관 단체 후보에서 제외
- Cloudtype 서버에서 문자나라 API 직접발송
- EUC-KR 인코딩 적용
- 문자나라 테스트 발송 버튼
- 개별 수동 문자 발송
- 개인 QR 접수 완료 시 좌석 안내 문자 자동발송
- 단체 QR 접수 완료 시 대표자에게 이번 배정 좌석 목록 문자 자동발송
- 모바일 반응형 강화
- PWA(홈 화면 설치형) 기본 지원
- 기존 JSON 백업 복원 유지

Cloudtype 환경변수
- ADMIN_PASSWORD
- MUNJANARA_ID
- MUNJANARA_PW
- MUNJANARA_SENDER
- MUNJANARA_TEST_RECEIVER
- SMS_RELAY_TOKEN (이제 직접발송에는 필요 없지만 예전 relay 호환용으로 남겨도 됨)

적용 전
1. 현재 서버에서 JSON 백업 다운로드
2. ZIP 파일을 GitHub 저장소에 덮어쓰기
3. Cloudtype 재배포
4. 데이터가 비었으면 백업 메뉴에서 JSON 복원
5. 문자 메뉴에서 '테스트 문자 발송' 먼저 확인
6. 개인 QR 1명 테스트
7. 단체 QR 1팀 테스트

주의
- Cloudtype 직접발송이 성공하면 집 PC relay는 더 이상 필요하지 않습니다.
- 전날 안내문자는 자동 일괄발송 UI를 제거하고 개별 발송 중심으로 변경했습니다.

# v0.8.1 · 777 스톱 행운권 추첨
- 기본 추첨대상: `도착 완료 + usesCenter(복지관 이용인) + 이전 미당첨자`
- 화면에는 `이름 (좌석번호)` 형식으로 빠르게 순환
- 추첨 준비 후 자동 회전, `SPACE`를 누를 때까지 계속 회전
- `SPACE` 입력 후 띠/띠/띠 4단계 감속
- 감속 시작 시 서버에서 crypto 기반 실제 당첨자 확정
- 최종 당첨자 + 좌석번호 대형 표시
- WebAudio로 회전 틱/감속음/당첨 팡파르 생성 (외부 음원 파일 불필요)
- 상품별 기존 유효 당첨건을 차감해 남은 수량 표시
- 상품 수량 소진 시 추가 추첨 차단
- 당첨취소 시 참가자는 다시 추첨대상이 되고 상품 남은 수량도 복구

※ 특정인을 숨겨서 일반 랜덤인 것처럼 보이게 당첨시키는 기능은 넣지 않았습니다.
  지정 대상이 필요하면 '별도 선정/보장 대상'으로 명확히 구분하는 방식으로 추가하는 것이 안전합니다.

# v0.8.4 · 버튼 치명 오류 수정 + 프리미엄 행운권 추첨
## 긴급 수정
- `app.js`에 잘못 남아 있던 단독 `async` 한 줄 제거.
- 이 오류 때문에 해당 줄 이후 JavaScript 이벤트가 등록되지 않아 여러 버튼이 동작하지 않던 문제 수정.
- 캐시 버전을 v0.8.4로 강제 갱신.

## 행운권 추첨 연출
- 3칸 슬롯 방식 제거.
- 한 개의 대형 세로 릴 방식으로 변경.
- 참가자 `이름 (좌석번호)`가 실제로 위아래로 연속 스크롤.
- SPACE를 누르기 전까지 계속 회전.
- SPACE 시점에 서버에서 실제 당첨자를 확정한 뒤 약 2.85초 동안 자연 감속하여 당첨자에 정확히 정지.
- 어두운 공연장용 프리미엄 배경: 은은한 스포트라이트, 앰비언트 글로우, 금빛 디테일, 유리질감 릴.
- 최종 당첨 시 전체화면 CONGRATULATIONS 연출 + 금빛 파티클.
- 기존 상품 등록/수량 관리, 복지관 이용인 필터, 이전 당첨자 제외, 당첨 취소/수령 처리 유지.
