v0.9.13 GitHub 전체 업로드본

이번 버전은 행사 당일 기준 안정화 버전입니다.

핵심:
1. 행운권 1~5명 동시 슬롯
   - 긴 세로 트랙 애니메이션 제거
   - 독립 슬롯 카드가 빠르게 이름을 교체
   - 멈춤 시 각 슬롯이 서서히 느려지고 당첨자에 고정
   - 전부 고정 후 최종 결과 화면
2. 상품 잔여수량이 3개면 기본 3명, 5개면 기본 5명(최대 5)
3. 사전 좌석은 내빈 / 휠체어 / 관리자 수동확정만
4. 일반 참가자는 당일 QR 접수 때 자동배정
5. 문자 좌석안내 링크 화면 완전 재작성

배포:
- JSON 백업 1회
- ZIP 전체를 GitHub 저장소 루트에 덮어쓰기
- Cloudtype 자동배포
- Ctrl+Shift+R
- 행사장 무대 페이지도 새로 열기

Cloudtype 환경변수 변경 없음.
Google Apps Script 변경 없음.
