[v0.9.10 GitHub 업로드]

이 ZIP은 nyjwel20th-admin-v2 저장소에 그대로 덮어쓰는 전체본입니다.

1. 현재 운영 데이터 JSON 백업 1회 다운로드
2. ZIP 압축 해제
3. 압축 안의 파일/폴더를 GitHub 저장소 루트에 그대로 업로드/덮어쓰기
4. Cloudtype 자동 재배포 확인
5. 관리자 페이지 강력 새로고침(Ctrl+Shift+R)
6. 행운권 > 컴퓨터 무대화면 열기
7. 무대 화면 시작 클릭
8. 휴대폰에서 추첨 시작/멈춤 테스트

Cloudtype 설정/환경변수는 새로 바꿀 것 없습니다.
Google Apps Script도 건드릴 필요 없습니다.
