v0.9.13 자체점검

[행운권]
- v0.9.12에서 무대 HTML과 새 다중슬롯 JS/CSS의 DOM 구조가 서로 맞지 않는 문제를 확인.
- v0.9.13에서 raffle-stage.html / raffle-stage.js / raffle-stage.css 구조를 완전히 통일.
- JS가 참조하는 정적 DOM ID와 HTML ID 일치 검사 통과.
- server.js / app.js / raffle-stage.js / seat-guide.js / demo.js Node 문법검사 통과.
- 긴 세로 transform 릴을 제거하고 독립 슬롯 카드 방식으로 변경:
  빠른 이름 교체 -> 단계 감속 -> 당첨자 고정.
- 1~5명 동시 슬롯 지원.
- 5개 슬롯은 약 0.42초 간격으로 감속을 시작해 전체 진행시간을 줄임.
- 상품 잔여수량이 3개면 기본 3명, 5개면 기본 5명으로 추천(최대 5).

[좌석]
- 사전배치는 내빈(vip/guest), 휠체어/장애인석, 관리자 수동확정(seatLocked)만.
- 일반 참가자는 미리 배치하지 않고 행사 당일 체크인 시 일반석 자동배정.
- 현재 도착자 자동배치는 도착 완료 + 미배정 참가자만 처리.

[문자 좌석안내]
- 누적된 구형 좌석 CSS/JS를 제거하고 새 구조로 완전 교체.
- A~L: 좌 8 / 런웨이 / 우 8.
- M~T: 1~20 x 8줄.
- 본인 좌석을 빨간색 펄스로 표시.
