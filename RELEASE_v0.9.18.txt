NYJWEL 20th Admin v0.9.18

1. 관리자 주소 유지
   - / : 기존 관리자 시스템 그대로

2. 초대장 전용 공개 페이지 추가
   - /9.18  (권장)
   - /invite, /918 도 같은 페이지로 연결
   - 이름 + 휴대전화번호 전체 일치 시 본인 초대장 표시
   - 이름 / 소속 / 좌석 / 개인 QR / 좌석 위치 링크 표시
   - 관리자 기능 및 명단 미노출

3. 총 400석 후면 확장
   - A~L 기존 좌석 구조 및 현재 배정 절대 변경 없음
   - M~P: 기존 20석 바깥에 좌측 2 + 우측 2 추가 (각 24석)
   - Q~T: 기존 20석 바깥에 좌측 1 + 우측 1 추가 (각 22석)
   - 기존 376석 + 추가 24석 = 총 400석
   - 기존 M~T 1~20 좌석코드도 변경 없음

4. 데이터 보존
   - 기존 state.json이 있으면 참가자/배정/접수 데이터는 그대로 사용
   - 서버 시작 시 새 확장좌석 24석 중 없는 좌석만 추가
   - 기존 좌석 삭제/재번호/재배치하지 않음
   - 좌석관리의 '400석 후면 확장 적용' 버튼도 추가좌석만 병합

주의: package.json에 qrcode 의존성이 추가되어 Cloudtype 재배포 시 npm install이 실행되어야 합니다.
